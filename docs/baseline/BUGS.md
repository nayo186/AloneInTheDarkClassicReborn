# Línea base: bugs y observaciones

Estado del juego **antes de empezar a arreglar cosas** (Fase 1 del `ROADMAP.md`). Sirve para comparar después de cada cambio y saber si un bug ya existía o lo introdujimos nosotros.

- **Fecha:** 2026-10-24
- **Commit:** tag `baseline` (incluye solo los avisos de datos incrustados, sin cambios de comportamiento)
- **Compilación:** RelWithDebInfo x64, Direct3D 11, ventana 1410x890
- **Datos:** una copia de los datos del juego, la carpeta `aitd1-data` (copia de GOG **sin archivos de audio**: música y voces)
- **Recorrido:** presentación → desván → primer piso (sala 6) → regreso al desván. Recoger la lámpara, el zombi entra por la ventana.
